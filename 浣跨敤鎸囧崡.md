# 浣跨敤鎸囧崡

## 1. Browse Rankings

Visit https://api-rank-lake.vercel.app to see the homepage.

### Filter Options

Click filter buttons to filter by:
- **All** - Show all active sites
- **Claude** - Sites supporting Claude models
- **GPT** - Sites supporting GPT models
- **Gemini** - Sites supporting Gemini models
- **Domestic** - Sites supporting DeepSeek/Qwen/Kimi/GLM
- **Low Price** - Budget-friendly sites
- **Enterprise** - Enterprise-grade sites
- **AI Drawing** - Sites supporting Midjourney/SD

### Search

Enter keywords in the search box to search by name, domain, or description.

## 2. View Site Details

Each card shows:
- **Score** - Overall rating (max 10)
- **Tags** - Supported model types
- **Metrics** - Positioning, pricing, features
- **Invite Link** - Click to register with bonus

## 3. View All Sites

Click "View All" to see the complete list.

## 4. Admin Panel

Visit admin.html for the merchant backend:
- Submit new sites
- Manage site info
- View review status

## Tips

1. Filter by model type first, then sort by price
2. Higher score = better overall performance
3. Use invite links for registration bonuses
4. Check the dead sites list to avoid unavailable platforms
