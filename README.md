## 📁 项目结构

```
api-rank/
├── index.html              # 首页（Top 50 + 动态加载 + 广告位轮播 + 快速选站器 + 随机盲选 + 最新收录）
├── all-stations.html       # 全部站点页面（166+，无数量限制）
├── about.html              # 关于本站（介绍 + 使用指南 + 收藏提示）
├── tools.html              # 🔥 实用工具（自研AI工具 + 精选服务导航）
├── img-prompt.html         # 图片反推提示词工具（多格式输出 + 历史记录）
├── creative-tools.html     # AI绘图/视频专区（在线生成）
├── news.html               # 相关新闻（2列卡片+右侧推荐+标签筛选+分页，34篇深度文章）
├── news/                   # 34篇独立URL的SEO文章（结构化数据+内部互链）
├── dead-sites.html         # 失效站点列表（动态加载，与首页交叉验证）
├── admin.html              # 商家管理后台
├── assets/
│   └── notice.js           # 全站顶部提醒横幅（换域名/收藏提示）
├── data/
│   ├── stations_info.json  # 主站点数据（166个，含added收录日期）
│   ├── dead_sites.json     # 失效站点记录
│   └── pending_stations.json # 待审核站点
├── api/                    # Cloudflare Workers 后端
│   ├── wrangler.toml       # Workers 配置
│   ├── schema.sql          # D1 数据库建表
│   └── src/
│       ├── index.js        # API 入口（注册/次数管理）
│       └── utils.js        # JWT/工具函数
├── scripts/                # 自动化脚本（已禁用自动检测，改为手动标记）
├── articles/               # 推广文章模板
├── .github/workflows/      # GitHub Actions（已禁用自动检测）
├── robots.txt              # 搜索引擎爬虫规则
├── sitemap.xml             # 站点地图
└── README.md
```

## 🚀 快速开始

### 在线使用
- 🇨🇳 **国内访问**（GitHub Pages）: [https://chenking-maker.github.io/api-rank/](https://chenking-maker.github.io/api-rank/)
- 🌍 **国际访问**（Vercel）: [https://api-rank-lake.vercel.app](https://api-rank-lake.vercel.app)

### 本地部署
```bash
git clone https://github.com/Chenking-maker/api-rank.git
cd api-rank
npx serve .
```

### Vercel部署
```bash
npm i -g vercel
vercel
```

### Cloudflare Pages部署
1. Fork 本仓库
2. 在 Cloudflare Pages 中连接 GitHub 仓库
3. 构建命令留空，输出目录为根目录

### 分享系统后端部署（可选）
```bash
cd api
npm install -g wrangler
wrangler login
wrangler d1 create api-rank-db  # 创建数据库
wrangler d1 execute api-rank-db --file=schema.sql  # 初始化表
wrangler secret put JWT_SECRET  # 设置JWT密钥
wrangler deploy  # 部署Workers
```

## ❓ 常见问题（FAQ）

<details>
<summary><b>什么是AI API中转站？</b></summary>

AI API中转站是聚合多家AI大模型API（如Claude、GPT、Gemini、DeepSeek等）的代理服务平台，提供统一接口、更低价格和更稳定的访问，帮助开发者降低AI调用成本。详见<a href="https://chenking-maker.github.io/api-rank/news.html">相关新闻</a>。
</details>

<details>
<summary><b>如何选择最适合的API中转站？</b></summary>

可以使用本站的「🎯 快速选站（适合你）」功能，填写你的需求（模型、预算、场景等），系统会智能推荐最适合的5个中转站，完全免费、无限次使用。也可以点击「🎁 随机盲选」试试手气。
</details>

<details>
<summary><b>快速选站器是免费的吗？</b></summary>

是的，完全免费、无限次使用。只需填写需求即可获得智能推荐，且只推荐带邀请链接的中转站，确保你能获得注册优惠。
</details>

<details>
<summary><b>失效站点会自动标记吗？</b></summary>

不会。已取消自动化检测，改为手动标记。只有站长确认某站点打不开后才会标记为失效，避免因网络波动导致误判。失效站点仍保留可点击链接，方便确认是否恢复。
</details>

<details>
<summary><b>这个项目是开源的吗？</b></summary>

是的，本项目完全开源，采用MIT许可证。所有站点数据、评分逻辑均可在GitHub上查看，数据透明可验证。
</details>
