## 📊 评分体系

本站采用7大维度综合评分，确保排名客观公正：

| 维度 | 权重 | 说明 |

## 📁 项目结构

```
api-rank/
├── index.html              # 首页（Top 50 + 动态加载 + 广告位轮播 + 分享系统）
├── all-stations.html       # 全部站点页面（139+，无数量限制）
├── creative-tools.html     # AI绘图/视频专区
├── dead-sites.html         # 失效站点列表
├── admin.html              # 商家管理后台
├── data/
│   ├── stations_info.json  # 主站点数据（139个）
│   ├── dead_sites.json     # 失效站点记录
│   └── pending_stations.json # 待审核站点
├── api/                    # Cloudflare Workers 后端
│   ├── wrangler.toml       # Workers 配置
│   ├── schema.sql          # D1 数据库建表
│   └── src/
│       ├── index.js        # API 入口（注册/分享/次数管理）
│       └── utils.js        # JWT/工具函数
├── scripts/                # 自动化脚本
│   ├── weekly_check.py     # 每周站点检测
│   ├── daily_check.py      # 每日可用性检测
│   └── crawler_v3.py       # 站点信息爬取
├── articles/               # 推广文章模板
│   ├── v2ex-promotion.md   # V2EX 推广帖
│   ├── zhihu-article.md    # 知乎评测文章
│   └── twitter-thread.md   # Twitter 推文串
├── .github/workflows/      # GitHub Actions 自动化
├── robots.txt              # 搜索引擎爬虫规则
├── sitemap.xml             # 站点地图
└── README.md
```

## 🚀 快速开始

### 在线使用
- 🇨🇳 **国内访问**（GitHub Pages）: [https://chenking-maker.github.io/api-rank/](https://chenking-maker.github.io/api-rank/)
- 🌍 **国际访问**（Vercel）: [https://api-rank-lake.vercel.app](https://api-rank-lake.vercel.app)

### 本地部署
```bash
git clone https://github.com/Chenking-maker/api-rank.git
cd api-rank
npx serve .
```

### Vercel部署
```bash
npm i -g vercel
vercel
```

### Cloudflare Pages部署
1. Fork 本仓库
2. 在 Cloudflare Pages 中连接 GitHub 仓库
3. 构建命令留空，输出目录为根目录

### 分享系统后端部署（可选）
```bash
cd api
npm install -g wrangler
wrangler login
wrangler d1 create api-rank-db  # 创建数据库
wrangler d1 execute api-rank-db --file=schema.sql  # 初始化表
wrangler secret put JWT_SECRET  # 设置JWT密钥
wrangler deploy  # 部署Workers
```

## ❓ 常见问题（FAQ）

<details>
<summary><b>什么是AI API中转站？</b></summary>

AI API中转站是聚合多家AI大模型API（如Claude、GPT、Gemini、DeepSeek等）的代理服务平台，提供统一接口、更低价格和更稳定的访问，帮助开发者降低AI调用成本。
</details>

<details>
<summary><b>API中转站比官方API便宜多少？</b></summary>

大多数中转站通过批量采购Token获得折扣，价格通常比官方API便宜30%-70%。部分中转站还提供免费额度和邀请奖励，进一步降低使用成本。
</details>

<details>
<summary><b>如何选择最适合的API中转站？</b></summary>

选择时需要考虑：1) 支持的模型种类，2) 价格与性价比，3) 响应速度与延迟，4) 稳定性与可用率，5) 是否提供免费额度，6) 数据安全与隐私保护。本站提供139+平台的实时评测排行，帮助您快速筛选。
</details>

<details>
<summary><b>排行榜数据是实时更新的吗？</b></summary>

是的，本站每日自动检测所有中转站的可用性，实时更新排名。检测维度包括延迟、价格、稳定性、模型真实性等7个维度，确保排名数据准确可靠。
</details>

<details>
<summary><b>这个项目是开源的吗？</b></summary>

是的，本项目完全开源，采用MIT许可证。所有站点数据、评分逻辑、检测脚本均可在GitHub上查看，数据透明可验证。
</details>
