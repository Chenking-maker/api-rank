API中转站常见问题FAQ：新手入门20问

整理了新手最高频的 20 个问题，按使用顺序排列，看完即可上手。

注册与 Key

  • Q1 中转站是什么？聚合多家大模型的统一代理网关，详见入门文章。
  • Q2 注册需要什么？多数只需邮箱，部分需要邀请码。
  • Q3 Key 在哪里创建？后台"API 令牌/密钥"页，建议按项目建多个子 Key。
  • Q4 Key 给别人用安全吗？不安全，Key 等于钱包，见Key 安全指南。

接入配置

  • Q5 base_url 填什么？站点文档里的兼容地址，通常以 /v1 结尾。
  • Q6 模型名怎么写？以站点"模型列表"页为准，别照抄官方名。
  • Q7 能用官方 SDK 吗？能，OpenAI 兼容接口都支持，见兼容接口详解。
  • Q8 支持流式输出吗？主流站都支持，参数与官方一致。

报错排查

  • Q9 401 是什么？Key 错误、余额不足或未开通该模型。
  • Q10 429 是什么？触发速率限制，降并发或升级套餐。
  • Q11 超时怎么办？换线路、缩短输入、检查本地代理冲突。
  • Q12 模型回答变笨？可能被降配，用特征题测试并联系客服。

账单与成本

  • Q13 Token 怎么算？输入输出分开计费，中文约 1~2 字/Token。
  • Q14 账单对不上？核对输入长度、系统提示与重试次数。
  • Q15 怎么省钱？小模型分流 + 缓存 + 限长，见优化技巧。

安全与其他

  • Q16 中转站能看到我的内容吗？技术上可以，敏感数据请脱敏。
  • Q17 会跑路吗？有可能，小额充值、关注危险信号。
  • Q18 能开发票吗？少数企业向站点支持，充值前确认。
  • Q19 手机能用吗？能，任何能发 HTTPS 请求的设备都行。
  • Q20 哪里看靠谱的站？本站排行榜持续更新评测。
