评分是怎么算出来的

高分不等于适合你。我们的评分由六个维度加权而成，其中可用性与稳定性权重最高，其次是价格透明度与模型覆盖：

  • 可用性（30%）：连续检测成功率、故障恢复速度、是否有公开状态页；
  • 稳定性与SLA（25%）：是否承诺SLA、是否有赔付条款、历史掉线记录；
  • 价格透明度（15%）：计价单位是否清晰、有无隐藏倍率、充值门槛；
  • 模型覆盖（15%）：主流模型是否齐全、是否标注"满血不降智"；
  • 响应速度（10%）：首Token延迟与并发承载；
  • 文档与服务（5%）：接入文档、客服响应、退款政策。

不同人群怎么选

  • 个人开发者：优先看起充门槛与是否支持人民币小额充值，先充5到50元跑通再说；
  • AI编程重度用户：重点看Claude与GPT分组是否保真、是否支持Prompt Caching，可参考Claude Code 中转配置指南；
  • 小团队：必须有子Key、用量报表与成员权限，详见团队选站指南；
  • 企业采购：SLA可签署、能开发票、支持对公转账是硬门槛，见企业采购指南。

三条避坑提醒

  1. 评分再高也要小额试充，先跑真实业务请求再放量；
  2. 警惕"限时超低价"营销，价格明显偏离官方定价的要先查是否降智或共享号池；
  3. 关注跑路信号：客服失联、提现困难、频繁换域名，可对照跑路前的5个危险信号。
