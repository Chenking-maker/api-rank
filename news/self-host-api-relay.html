自建API中转站教程：用New API搭建统一模型网关

一、为什么要自建API中转站

自建API中转站的好处在于：完全掌控数据安全、自由添加渠道、无中间商赚差价、可以自定义限流和计费规则。适合有一定运维能力的开发者和小团队。

二、方案选型：New API vs One API

New API是One API的社区升级版，修复了大量bug并增加了新功能，推荐使用。核心优势：

  • 支持更多模型渠道（100+）
  • 更好的用户界面和管理后台
  • 活跃的社区维护
  • 支持Docker一键部署

三、Docker部署步骤

1. 环境准备

需要一台服务器（推荐2核4G以上），安装Docker和Docker Compose。国内服务器建议配置镜像加速。

2. 一键启动

使用Docker Compose部署，创建docker-compose.yml：

  • 数据库：MySQL或SQLite
  • Redis：用于缓存和限流
  • New API：主服务

执行docker-compose up -d即可启动，默认端口3000。

3. 初始配置

  1. 访问 http://your-server:3000
  2. 使用默认管理员账号登录
  3. 立即修改密码
  4. 配置系统设置（站点名称、注册策略等）

四、添加模型渠道

1. 添加OpenAI渠道

  • 类型选择 OpenAI
  • 填入官方API Key
  • 设置可用模型列表

2. 添加Anthropic（Claude）渠道

  • 类型选择 Anthropic
  • 填入Claude API Key
  • New API会自动将Claude接口转换为OpenAI兼容格式

3. 添加国产模型渠道

New API支持DeepSeek、Qwen、GLM、Kimi等国产模型，配置方式类似，填入对应API Key即可。

五、创建用户和密钥

  1. 在用户管理中创建用户
  2. 为用户分配额度
  3. 用户登录后创建API Key
  4. 配置Key的可用模型和速率限制

六、高级配置

1. 负载均衡

为同一模型添加多个渠道，New API会自动负载均衡，提升可用性。

2. 渠道分组

将不同渠道分组，按优先级调度，实现容灾切换。

3. 限流策略

  • 按用户限流
  • 按IP限流
  • 按Token限流

4. 日志监控

New API内置详细的调用日志，支持按用户、模型、时间筛选，方便排查问题。

七、安全建议

  1. 使用HTTPS（配置Nginx反向代理+SSL证书）
  2. 关闭公开注册或开启邀请码注册
  3. 定期备份数据库
  4. 设置强密码并开启两步验证
  5. 限制管理员登录IP

八、成本对比

自建中转站的成本主要是服务器费用和官方API费用，相比使用第三方中转站：

  • 优势：无中间商加价，数据安全可控
  • 劣势：需要运维成本，服务器费用
  • 适合：月调用量较大的团队或个人

如果你不想自己维护，可以直接使用我们排行榜中评分较高的第三方中转站。
