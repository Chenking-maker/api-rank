Claude Code 中转站使用指南：配置与常见问题

Claude Code 是 Anthropic 官方的命令行编程助手，能力很强，但直接使用官方订阅成本较高、且对网络有要求。通过 API 中转站接入，可以用更低的价格、国内直连的方式跑起来。本文给出完整配置方法。

一、为什么用中转站跑 Claude Code

Claude Code 本质上是调用 Anthropic 的 Messages API。中转站只要兼容该接口，就能作为后端。使用中转的好处：

  • 国内网络直连，不需要自建代理；
  • 按量付费，成本通常是官方的三到七折；
  • 可以随时切换到其他模型做对比。

二、环境变量配置

Claude Code 通过两个环境变量指定中转地址与密钥：

ANTHROPIC_BASE_URL 填中转站提供的兼容地址（一般以 /v1 结尾或直接是站点域名）；ANTHROPIC_AUTH_TOKEN（或 ANTHROPIC_API_KEY）填你在中转站申请的 Key。

  • Windows：在"系统属性 → 环境变量"中新增，或使用 setx 命令；
  • macOS/Linux：写入 shell 配置文件后再 source；
  • 配置完成后重开终端，运行验证命令确认生效。

三、常见报错与解决

  • 401 未授权：Key 填错、余额不足、或该中转不支持 Anthropic 协议。
  • 404 / model not found：模型名要按中转站的命名，例如有的写 claude-sonnet-4，有的带前缀。
  • 超时：切换到更快的线路，或检查本地网络与代理冲突。
  • 连接被重置：多半是地址写成了带 /v1/v1 的重复路径。

四、成本控制建议

Claude Code 会频繁读取代码上下文，Token 消耗不低。建议开启按量计费、设置每日上限，并优先选择有缓存折扣的中转。同时避免让它一次性扫描超大仓库。

五、注意事项

务必选择口碑好、经营时间长的中转，坚持小额充值。更多排查方法可参考API 中转站常见报错排查。
