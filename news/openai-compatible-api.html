什么是OpenAI兼容接口？为什么所有中转站都用它

你会发现几乎所有中转站都写着"支持 OpenAI 兼容格式"。这到底是什么意思？为什么大家都选它？

一、什么是 OpenAI 兼容接口

指 API 的地址结构、请求参数、返回字段都与 OpenAI 官方一致：对话接口是 /v1/chat/completions，参数有 model、messages、temperature 等，返回里有 choices[0].message.content。任何兼容这套格式的服务，都能直接用 OpenAI 官方 SDK 调用——只需把 base_url 换成中转地址、把 api_key 换成中转 Key。

二、为什么它成了事实标准

  1. 生态最大：OpenAI SDK 支持所有主流语言，工具链最成熟；
  2. 迁移成本为零：换模型、换平台只改两行配置，代码不动；
  3. 中转站的自然选择：把 Claude、Gemini、DeepSeek 都翻译成同一格式，用户一套代码调所有模型。

三、实际调用示例（思路）

用官方 SDK 初始化时传入中转站的 base_url 和 Key，然后把 model 参数填成中转站支持的模型名（如 claude-sonnet-4、deepseek-chat），其余代码与调用 OpenAI 完全一样。

四、兼容并不等于完全相同

  • 部分高级参数（如 logprobs、某些工具调用细节）各家支持程度不同；
  • 流式输出的事件字段可能略有差异；
  • 报错格式与状态码未必与官方一致。

迁移后建议先用真实业务跑一遍冒烟测试，再正式切换。入门背景可参考什么是API中转站。
