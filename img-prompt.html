💡 使用技巧

  • 分析需使用支持视觉的模型（如 GPT-5-mini、Gemini、Claude 系列），图像生成模型（GPT Image 2.5 等）无法识别图片。
  • GPT 生图格式输出自然语言段落，可直接粘贴到 GPT Image 2.5 / DALL-E 3 中使用，比例用文字描述。
  • Midjourney 格式自动附带 --ar 画幅参数，负面内容以 --no 形式给出，适配 Midjourney V7。
  • SD 格式自带 (keyword:1.2) 权重标记，适配 Stable Diffusion 4 / SDXL。
  • 历史记录仅保存在你的浏览器本地（最多 20 条），可随时点击卡片恢复结果。

🔐 隐私与安全

  • API Key 与历史记录全部保存在本地浏览器，本站不存储、不上传。
  • 请求由你的浏览器直接发往你所选的 API 平台，不经过第三方服务器。
  • 建议使用额度有限的 Key，并定期在平台后台检查用量。
